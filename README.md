## 常见问题

**Evoxt 到底收不收 USDT？走哪条链？**

**能不能加配置或者换套餐？**
官方价格页写明可以在不换套餐的前提下单独增加 CPU、内存、存储，按需加资源比整档升级灵活。

**USDT 转错链了怎么办？**
转错网络的钱不会进入订单，也基本无法追回。转账前把网络、地址、金额三项各核对一遍，这是唯一有效的办法。

**超时没开通怎么办？**
Evoxt 本次核验的页面里没有超时赔付条款。市场上有的商家把"24 小时内开通、超时全额退款"写进页面，Evoxt 没有同类明文承诺。真遇到卡单，带上 txid 联系客服是唯一路径。
